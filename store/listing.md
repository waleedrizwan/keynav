## Store listing tab

**Name** (from manifest): Keynav

**Summary** (from manifest, max 132 chars):
Mouse-free browsing: label every clickable element and hit it with the keyboard.

**Category:** Productivity → Tools

**Language:** English

**Description:**

```
Browse the web without reaching for the mouse.

Press F and Keynav puts a short label on every link, button and field on the page. Type the label and it's clicked. That's it.

KEYS
• F – label everything clickable; type a label to click it
• Shift+F – same, but links open in a background tab
• ; – step through clickables with J/K, Enter to click
• gi – jump into the first text field
• J / K – scroll down / up; D / U – half a page
• gg / Shift+G – top / bottom
• Shift+H / Shift+L – back / forward
• Shift+J / Shift+K – next / previous tab
• T / X – new tab / close tab
• R – reload
• ? – show all keys
• Esc – cancel, or leave a text field

FINDS WHAT OTHER TOOLS MISS
Keynav doesn't only look for links and buttons. It also spots the clickable divs and custom controls that modern web apps build with JavaScript, looks inside web components (open shadow DOM), and skips anything hidden or covered up so labels only appear where you can actually click.

STAYS OUT OF YOUR WAY
• Keys are ignored while you're typing in a field, and whenever Ctrl, Cmd or Alt is held.
• Labels are drawn in an isolated layer, so page styles can't break them.
• Web pages can't trigger Keynav with fake key presses.

PRIVATE BY DESIGN
No accounts, no analytics, no network requests, no storage. Keynav never reads, saves or sends anything about the pages you visit.

OPEN SOURCE
MIT licensed: https://github.com/waleedrizwan/keynav

Known limits: Chrome doesn't allow extensions on chrome:// pages, the Chrome Web Store or the new-tab page, and Keynav doesn't label inside iframes yet.
```

## Privacy tab

**Single purpose:**
Keynav lets users click links, buttons and other controls on web pages, scroll, and switch tabs using only the keyboard.

**Host permission justification** (content scripts on `<all_urls>`):
Keynav's purpose is keyboard navigation on any website the user visits, so its content scripts must run on all pages. They only react to the user's own key presses: on request they find clickable elements on the current page, draw labels over them, and click the one the user picks. No page data is read for any other purpose, stored, or sent anywhere.

**Remote code:** No, I am not using remote code. All JavaScript is included in the package.

**Data usage:** Collects none of the listed data types.
Certifications (the account owner must tick these personally):
