# Security Policy

## Supported versions

Only the latest release of Keynav receives security fixes.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report them privately through GitHub instead: go to the [Security tab](https://github.com/waleedrizwan/keynav/security) and click **Report a vulnerability**. You'll get a response within a week, and a fix or mitigation as soon as practical. Reporters are credited in the release notes unless they'd rather not be.

Keynav runs on every page you visit, so issues that would let a web page abuse the extension (for example, to trigger clicks, open tabs or run script) are in scope.
